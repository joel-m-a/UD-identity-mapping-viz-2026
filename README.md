# UD-identity-mapping-viz-2026 📊

### Multivariate Analysis of Classroom Dynamics & Professional Identities

## 📝 Project Overview
This project presents an exploratory and multivariate analysis of the 2026 Data Visualization cohort. Using data collected from 22 students, the study explores how interests in areas like Mathematics, Arts, and Programming intersect to create unique professional archetypes.

The analysis focuses on:
*   **Global Structure**: Identifying patterns that define the group's identity.
*   **Individual Positioning**: Mapping specific profiles (like my own) within a high-dimensional feature space.

## 🛠️ Tech Stack & Methodology
*   **Language:** R
*   **Environment:** Quarto (HTML output with embedded resources)
*   **Key Libraries:** `tidyverse`, `factoextra` (PCA), `pheatmap` (Distance Matrices), `GGally` (Parallel Coordinates).
*   **Techniques Applied:**
    *   **Anonymization:** Data was anonymized using Student IDs to protect privacy.
    *   **Distance Metrics:** Euclidean and Manhattan distances to find "Data Twins".
    *   **PCA (Principal Component Analysis):** Dimensionality reduction to visualize a 25D space in 2D.

## 💡 Key Insights
*   **Archetype Clustering:** The group naturally splits into "Technical-Academic" and "Industry-Creative" profiles.
*   **Outlier Identification:** PCA successfully isolated unique profiles that deviate from the class average due to specific artistic interests.
*   **My Profile:** Located in the **Bottom-Right quadrant**, representing a balanced profile between technical core skills and creative inclinations (Acting/Gaming).
